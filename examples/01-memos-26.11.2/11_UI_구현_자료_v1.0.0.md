## 2. 라우트 및 화면 상태별 레이아웃 구조 (`F-011`)

| 화면 ID | 실제 라우트 (`url_path`) | 레이아웃 셸 | 핵심 컴포넌트 구성 | 상태별 변형 규칙 |
| :--- | :--- | :--- | :--- | :--- |
| `UI-01` | `/auth/signup` | 인증 단독 중앙 카드 (`nav_present: false`) | 브랜드 헤더(`Memos`), 안내 문구(`Set up your instance`), `Username`/`Password` 입력, `Create admin account` 버튼, 언어 선택기 | `GET /api/instance/profile`의 `needsSetup: true`일 때 자동 리다이렉트 진입 |
| `UI-02` | `/` | 앱 셸 좌측 내비게이션 + 본문 작성기 + 우측 달력/필터 사이드바 (`nav_present: true`) | 좌측 메뉴(`Timeline`, `Calendar`, `Map`, `Attachments`, `Search`), 월간 활동 캘린더, `Views`(`Create view`), 메모 작성기(`Only me` 기본 가시성, `Save` 버튼) | 메모 0건 빈 상태: 작성기 하단에 빈 입력 검증 안내 표시 |
| `UI-03` | `/` | 앱 셸 3단 구성 | 고정(`pinned`) 메모 상단 정렬, 본문 Markdown 렌더링, 체크박스(`- [x]`), 우측 `Tags` 카운트 목록(`architecture 1`, `audit 1`, `release 1`, `security 1`) | 작성 후 즉시 목록과 태그 카운트 갱신 |
| `UI-04` | `/?filter=tag+in+%5B%22release%22%5D` | 앱 셸 + URL 쿼리 필터 동기화 | URL `filter` 파라미터에 연동된 필터링 타임라인 | 필터 해제 시 전체 목록 복원 |
| `UI-05` | `/memos/:uid` | 앱 셸 + 단일 메모 상세 카드 | 상단 액션 바(`Edit`, `Write a comment`, `Share`), 작성자·본문·체크리스트, 하단 `Comments` 영역 | 소유자에게 수정·공유 액션 노출 |
| `UI-06` | `/archived` | 앱 셸 + 보관 목록 | `Archived` 배지 및 타임스탬프가 표시된 보관 메모 카드, `archive-test` 태그 카운트 분리 | 일반 타임라인(`/`)에서 제외되고 `/archived`에만 노출 |
| `UI-07` | `/auth?redirect=%2Fexplore` | 인증 단독 카드 (`nav_present: false`) | `Sign in` 폼 + `redirect` 쿼리 파라미터 보존 | 기본 `accessMode=PRIVATE` 인스턴스에서 비인증 `/explore` 진입 시 자동 리다이렉트(비공개 메모 `50%_off` 완전 비노출) |
| `UI-08` | `/auth?redirect=%2Fexplore` (`390x844@2x`) | 모바일 단일 컬럼 중앙 정렬 | 데스크톱과 동일한 폼 구조를 수평 스크롤 없이 390px 폭에 맞춤 | 뷰포트 `390x844`, DPR `2`에서 가로 오버플로 `0px` 유지 |

## 3. 에셋·라이선스 교체 규칙 (클린룸 재구현 주의사항)
- 프론트엔드 핵심 UI 기본 요소는 `@base-ui/react`, `lucide-react`, Tailwind CSS v4(`oklch` 색상 공간) 조합으로 구성되어 있습니다 (`[REF: web/package.json:18-55]`).
