## 3. 비교 허용 오차, OS 분기 및 미검증 범위

- **결정론적 비교 필드 vs 제외 필드**: HTTP 상태 코드, JSON 부울/열거형/개수/정렬 태그 집합, SQLite 테이블 집합은 정확 일치(허용 오차 `0`)를 요구합니다. 자동 생성 타임스탬프(`createTime`, `updateTime`), 랜덤 리소스 UID, JWT 문자열 본문은 비결정적 값으로 간주해 구조·존재 여부만 비교합니다.
- **시각 허용 오차(`05` UI 대조 시)**: 동일 뷰포트(`1440x900@1x`, `390x844@2x`)에서 레이아웃 영역·텍스트 가시성·라우트 리다이렉트 일치를 필수 기준으로 하며, 폰트 서브픽셀 렌더링 차이에 대해 SSIM ≥ `0.95` 또는 픽셀 차이 ≤ `3%`를 권장합니다(OS별 시스템 글꼴 차이 분기: macOS `-apple-system` vs Linux `sans-serif` vs Windows `Segoe UI`).
- **미검증 범위(확인된 일치 범위 한정)**: 본 통과 결과는 macOS `arm64` SQLite 단일 노드 환경의 `T-001`~`T-011` 사례에 한정됩니다. Linux/Windows 배포본, MySQL/PostgreSQL 드라이버, OAuth2/S3/SMTP/AI 외부 연동(`F-012`), 부하 상태에서의 `--rate-limit=true` 임계값은 미검증이며 별도 테스트 대역·OS 매트릭스 실행이 필요합니다.
