## 2. 대표 입출력·오류 예제

### 2.1 정상 요청 — 메모 생성 (`F-006`, `POST /api/memos`)
```json
{
  "content": "# Release Readiness\nVerified checksum #release #architecture",
  "visibility": "PUBLIC",
  "pinned": true
}
```
기대 응답 핵심 필드 (`pinned`는 생성 시 무시되어 `false` 유지):
```json
{
  "name": "memos/<generated_uid>",
  "creator": "users/specadmin",
  "visibility": "PUBLIC",
  "state": "NORMAL",
  "pinned": false,
  "tags": ["release", "architecture"]
}
```

### 2.2 오류 응답 — 비인증 보호 경로 접근 (`F-003`, `GET /api/auth/me`)
```json
{
  "code": 16,
  "message": "unauthenticated",
  "details": []
}
```
HTTP 상태 코드는 `401 Unauthorized`, 응답 헤더는 `Cache-Control: no-store`를 포함해야 합니다.
