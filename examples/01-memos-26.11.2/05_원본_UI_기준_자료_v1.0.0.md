## 3. 조작 순서 재현 절차
1. 신규 격리 SQLite 인스턴스 기동 후 `GET /` 접속 → `/auth/signup` 자동 전환 촬영 (`UI-01`).
2. `POST /api/users`로 최초 호스트 생성 후 `/auth` 폼 로그인 → `/` 빈 타임라인 촬영 (`UI-02`).
3. 합성 메모 4건 생성·고정(`M1`)·보관(`M3`)·삭제(`M4`) 수행 후 `/` (`UI-03`), `/?filter=tag+in+%5B%22release%22%5D` (`UI-04`), `/memos/<M1_uid>` (`UI-05`), `/archived` (`UI-06`) 순차 촬영.
4. 쿠키 없는 신규 컨텍스트로 `/explore` 접속 → `/auth?redirect=%2Fexplore` 리다이렉트 데스크톱(`UI-07`) 및 모바일 `390x844@2x`(`UI-08`) 촬영.
