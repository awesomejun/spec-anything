# 2048 · 첫 공개 예제 후보
목표는 한 판에서 타일을 합쳐 2048을 만들고, 계속하기 또는 새 게임을 선택하는 것이다. 원본 웹 게임의 데스크톱 플레이가 범위다.

| 기능 | 사용자가 한 일 | 수용 조건 |
|---|---|---|
| F01 | 빈 저장소로 시작 | 4×4 칸에 두 타일, 현재 점수 0 |
| F02 | 같은 수를 밀어 합치기 | 2·2·4를 왼쪽으로 밀면 기존 타일은 4·4가 된다. 각 병합값을 점수에 더하고 바뀐 턴에만 한 타일을 낸다. |
| F03 | 새로고침 또는 새 게임 | 새로고침은 진행판을 복원한다. 새 게임은 현재 점수를 0으로 만들고 최고 점수를 유지한다. |
| F04 | 1024 두 개를 합쳐 계속하기 | 2048과 승리 안내가 나타난다. 계속하기 직후 새로고침하면 승리 안내가 다시 뜬다. 유효한 이동 후에는 계속하기가 저장된다. |
| F05 | 마지막 빈 칸이 채워지고 가능한 병합이 사라짐 | 패배 상태가 되고 진행판을 지운다. 다음 실행은 두 타일로 시작한다. |

각 조건의 실제 입력과 결과는 03에서 같은 기능 ID로 찾을 수 있다.
