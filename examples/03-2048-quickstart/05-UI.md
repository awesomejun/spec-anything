# 화면 관찰
05-start.png는 저장 상태가 없는 원본의 첫 화면이다. 초기 두 타일과 점수 0을 확인했다. 05-win.png는 합성 시작판을 로드하고 왼쪽 화살표를 한 번 눌러 촬영했다. 1024 두 개가 합쳐진 자리, 점수·최고 점수 2048, You win!과 계속·재시도 버튼이 동시에 보인다. 800×900의 실제 뷰포트다. 브라우저가 일부 WOFF 요청에 캐시 오류를 보고해 정확한 글꼴 일치는 미확인이다.
  
별도 로딩 화면은 원본에 정의되지 않는다. 0타일 판은 일반 초기화에서 두 타일이 즉시 생겨 독립 화면으로 관찰되지 않는다. 패배는 엔진에서 확인했으며 화면은 승리 캡처로 대체하지 않았다.
