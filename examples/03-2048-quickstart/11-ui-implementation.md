# 화면 구성
상단 제목·현재 점수·최고 점수 → 목표 문구·New Game → 4×4 보드 → 조작법 순이다. 보드는 고정 배경 셀 위에 이동 타일 레이어와 승리/패배 메시지를 겹친다. 정상 상태는 05-start.png, 승리는 05-win.png가 기준이다. 데스크톱 보드 너비 500px, 패딩과 셀 간격 15px, 520px 이하 보드 280px. 배경 #faf8ef, 본문 #776e65, 보드 #bbada0. 원본의 Clear Sans 및 폴백 순서를 style/main.css에서 확인한다. 합쳐지는 원래 두 타일은 렌더 트리에 잠시 남으므로 DOM 타일 개수를 저장판의 타일 개수로 해석하면 안 된다. 모바일 레이아웃은 CSS 확인 범위다.
