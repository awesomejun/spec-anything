# 구현 순서
1. F01 격자 직렬화와 F02 방향별 스캔을 먼저 구현한다. start·pair·once·two-pairs·blocked가 통과하면 합치기 규칙을 고정한다.
2. F03 저장 어댑터와 UI 골격은 병렬로 구현한다. 첫 종단 흐름은 방향키 → 타일 병합 → 점수 갱신 → 새로고침 → 같은 판 복원이다. persist·restart를 통과해야 한다.
3. F04·F05 종료와 복구를 연결한다. 나머지 네 가지 종료 관련 시험과 브라우저 B-win-reload를 검증한다. 저장·렌더의 순서도 일치해야 한다.
4. 기기별 스와이프, 글꼴, 브라우저 저장 차단과 모바일 화면을 후속 검증한다. 데스크톱 실측의 수용 범위를 모바일까지 확장하려면 해당 플랫폼의 관찰과 캡처를 추가한다.
